\# PrivacySentry AI



PrivacySentry AI is an intelligent personal privacy protection system that scans text for common privacy-sensitive information.



\## Features



\- Detects privacy-sensitive information in text

\- Simple Streamlit web interface

\- Privacy and security focused

\- Runs locally



\## Technology



\- Python 3.12

\- Streamlit 1.40.1

\- python-dotenv

\- Requests

\- Pandas

\- NumPy

\- Scikit-learn

\- Pydantic



\## How to Run



Activate the virtual environment and run:



```bash

streamlit run app.py
